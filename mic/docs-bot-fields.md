# Поля заявки в боте «Сопровождение МИЦ»

Порядок соответствует диалогу в MAX. Шаги с пометкой «только для ошибки» или
«только для доработки» показываются в зависимости от первого ответа.

| # | Поле | Вопрос бота | Как отвечают | Куда попадает в Planfix / YouTrack |
|---|------|-------------|--------------|-------------------------------------|
| 1 | Тип заявки | Что оформляем? | кнопки: Ошибка / Доработка | поле «Тип заявки»; в YouTrack ещё Type = Bug / Task («Задание»); для ошибки заполняется «Где выявлено» |
| 2 | Клиника | Из какой вы клиники? | кнопки, 14 клиник (список ниже) | поле «Клиника»; по ней — инженер-исполнитель, «Объект» в YouTrack и группа, которой видна задача |
| 3 | Модуль | В каком модуле МИС проблема? / Какого модуля касается доработка? | кнопки: ЭМК, Локус (регистратура/расписание), Касса, ЛИС (лаборатория), Аптека, Отчётность / реестры, Другое | поле «Модуль» |
| 4 | Роль | Какая у вас роль в МИС? | кнопки: Врач, Медсестра, Регистратор, Кассир, Администратор, Лаборант, Статистик, Руководитель, или свой вариант текстом | поле «Роль» |
| 5 | Пользователь | Кто столкнулся с проблемой? / От кого доработка? | текст: ФИО и логин, например «Иванов А. А. / логин 123» | описание задачи |
| 6 | Пациент | Если проблема на конкретном пациенте — номер карты и КБП | текст, можно пропустить; только для ошибки | поле «Пациент» |
| 7 | Суть | Опишите суть ошибки / доработки одной фразой | текст | заголовок задачи и описание |
| 8 | Шаги | Что вы делали по шагам, пока не столкнулись с ошибкой? | текст; только для ошибки | описание |
| 9 | Фактический результат | Что получилось в итоге? | текст; только для ошибки | описание |
| 10 | Ожидаемый результат | А что должно было произойти? | текст; только для ошибки | описание |
| 11 | Что сделать | Что именно нужно сделать или изменить? | текст; только для доработки | описание |
| 12 | Зачем | Зачем это нужно? Какой эффект ожидаете? | текст; только для доработки | описание |
| 13 | Срочность | Насколько это срочно? | кнопки: Блокирует работу (полный отказ) / Мешает, есть обходной путь / Незначительно / пожелание | поле «Срочность»; в YouTrack ещё Priority = Critical / Major / Minor |
| 14 | Контакт | Как с вами связаться, если понадобятся детали? | текст: телефон, почта или мессенджер | поле «Контакт заявителя» |
| 15 | Вложения | Приложите скриншоты, видео или лог | до 10 файлов, можно пропустить | файлы задачи |

## Заполняется автоматически

| Поле | Значение |
|------|----------|
| Номер заявки | номер задачи YouTrack, например MIC-12, со ссылкой `https://yt.medinfocenter.ru/issue/MIC-12`; пока YouTrack не ответил — временный `ТП-<год>-<номер>` |
| Месяц создания (YouTrack) | месяц оформления, `2026.10` |
| Видимость (YouTrack) | группа «Клиенты … (объект)» своей клиники + команда проекта |
| Источник | «бот MAX» |
| Приоритет | по срочности: Блокирует → P0/P1 (SLA 1 час / 4 часа), Мешает → P2 (4 дня), Незначительно → P3/P4 (по плану релизов); пишется в заголовок и описание |
| Заказчик (Planfix) | контакт заявителя по имени из MAX; если нет — создаётся |
| Исполнитель | по клинике: в Planfix — сотрудник, в YouTrack — поле «Разработчик» |

## Где менять

- Списки клиник, модулей, ролей, срочностей и привязка инженеров — `ticket.mjs`.
- Тексты вопросов, подсказки и порядок шагов — `bot/dialog.mjs`.
- Названия полей в Planfix — `bot/planfix.mjs` (`FIELD_NAMES`), в YouTrack — `bot/youtrack.mjs`.
