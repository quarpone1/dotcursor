# Заявки по клиникам: MAX → YouTrack и Planfix

Актуальная схема с 04.11.2026: у каждой клиники свой проект YouTrack.
MIC не принимает новые заявки. Отдельные проекты созданы администратором.

Пользователь один раз подтверждает свой телефон кнопкой MAX. Бот находит
его в частном реестре, подставляет клинику и контакт. Для клиник без
реестра остаётся ручной выбор. В реестре 33 контакта из 9 клиник.
Контакт вручную не вводится: подтверждённый телефон и данные MAX;
если телефона нет — имя/ник и ID аккаунта.

## Что происходит после отправки

1. Пользователь заполняет анкету, проверяет карточку и нажимает
   «Отправить в поддержку». «Готово» после файлов показывает только
   карточку проверки; оно ещё не отправляет заявку.
2. Создаётся задача в проекте клиники, с инженером, полями и вложениями.
3. Пользователь получает номер YouTrack и короткую ссылку на задачу.
4. В Planfix создаётся дубль с тем же номером и ссылкой.
5. Подписанный инженер получает уведомление в MAX с кнопкой «В работу».
6. Комментарии инженера и файлы из YouTrack или Planfix идут клиенту в MAX.
   Ответ клиента из MAX дублируется в обе системы.

Клиент видит задачи своего объекта через права своего проекта, инженер
работает в проекте клиники. Новые задачи не используют группы видимости MIC.
Комментарии Planfix и YouTrack между собой не копируются.

## Поля и старые задачи

«Объект» — по клинике, «Где выявлено» — только для ошибки,
«Месяц создания» — ГГГГ.ММ, «Разработчик» — закреплённый инженер,
Type — Bug для ошибки и Task («Задание») для доработки.

После переноса меняется номер, но сохраняются сама задача, её комментарии,
вложения и внутренняя связь с отправителем MAX. Бот обновляет номера в своей
памяти и продолжает переписку; повторные копии задач не создаются.

Инженеры подписываются командой `инженер <логин> <код>`, старший —
`инженер <логин> все <код>`. Исполнитель должен состоять в команде проекта.

Реестр телефонов находится на сервере отдельно от Git. Роли и пользователей
клиник администратор назначает в соответствующем проекте YouTrack.
